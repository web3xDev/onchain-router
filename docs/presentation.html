The problem

An agent that needs onchain data today has to become a customer first

Sign up for each providerAPI keys, dashboards, rate limits, a card on file. Per source. Before the first useful call.
Pay for access, not answersSubscriptions charge whether the data was useful or not. An empty result costs the same as a good one.
Get rows, not verdicts27 lending markets come back as 27 objects. Which one is stale, which one is a trap, which one can you actually withdraw from: the agent has to work it out itself.
Nobody can list a toolEvery provider is its own island. There is no place an agent can discover what exists and what it costs.

OnchainRouter
The product

A catalogue of paid onchain tools, one endpoint, pay per call

DiscoverOne MCP URL, or plain HTTP. The agent lists every tool and its price for free.
Pay per call, from the agent's own walletEvery call returns 402 with the price and the rails. The agent signs with x402; the router never holds a key or a balance.
Get a verdictEvery tool turns onchain state into a decision, and says when the data cannot be trusted.
No answer, no chargeA tool with nothing to say never settles the payment. You buy verdicts, not attempts. Enforced on HTTP and MCP alike.
0% commissionEvery tool names its payout address. Each call settles from the agent's wallet straight to the author. An existing x402 endpoint can be listed as is; the router relays and takes nothing.

Arc and Circle

Autonomous USDC payments on Arc, signed by a Circle agent wallet

Circle developer-controlled walletThe agent's wallet lives in Circle. The router's wallet MCP asks Circle to sign the EIP-712 payment; the private key never reaches the machine.
Circle Gateway as x402 facilitatorVerifies the signature and settles USDC in batches. Gasless for the payer, which is what makes a one-cent price possible.
Settles to the tool authorThe 402 names the author's Arc address. Money goes agent → author. The router is never in the middle.
